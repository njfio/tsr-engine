## Task and honest interpretation

Two fictional desires seek a dependable small starting selection and continued
discovery of distinct perspectives. The public contract specifies size, valid
available IDs, repeatability, coverage and maximal retention of previous IDs
subject to those obligations. It supplies no preferred implementation or output.
The fixed external tests must judge those properties independently of the engine.

The two records illustrate initial and changed input availability. Both are
available from the outset; their bodies are uniformly withheld until a permitted
read. They are authored examples, **not a live changing environment**, observed
test results or actual human preferences. There is no after-pass reveal callback,
secret acceptance change, required failed patch or mandatory read order. A single
read may select both records. Their actual content-bound read receipt establishes
access and identity only. Only sealed program execution establishes test outcomes.

This test offers a complete native information → proposal/action → observed return
→ reviewed retention/development → subsequent pursuit path, without requiring that
trajectory. Initial relational guidance, information seeking and revision are
optional. A general correct implementation may pass immediately; abstention or
unchanged meaning may be justified. Such results do not demonstrate adaptive
relationship development, and will not trigger resampling.

The reader is a reviewed uncertainty/exploration route inside the native cycle,
not a competing patch scored using access probability. PRD B7 requires a common
task-acceptance event to compare unlike actions; that mixed-action estimator is
not implemented here. Access forecasts are separate diagnostics. Subsequent
project possibilities return to the existing selector with the new receipt.

## Evaluation and falsification

The frozen `rubric.json` distinguishes task correctness, information access,
reviewed memory, actual return, relationship development and subsequent use.
Access alone cannot meet the primary endpoint. A citation, new wording or unused
stored relationship is insufficient. Dropping an original parent, claiming unrun
checks passed, evaluator-authored meanings or manually steered actions invalidate
the relevant claim. Retention, no difference and inability remain reportable.

No paid baseline is included. Current code provides no clean equal-information
operational ablation: deleting the relation removes information; merely calling
it ordinary memory changes framing. Ordinary memory plus the same model could
explain a later adaptation. This batch can establish behavioral continuity, not
causal TSR advantage, general reliability or nonphysical measurement.
