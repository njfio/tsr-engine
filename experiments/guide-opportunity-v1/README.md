# Guide opportunity v1 — prospective, no live authority

This packet reuses the finite native objective and three frozen public graph
conditions. Contributing wants remain dependable orientation and approachable
unfamiliar perspectives. It changes the observational protocol, not the minimum
acceptance or desired relationship. All conditions and the protocol are fixed
before any model response. No historical experiment is regraded.

For each disclosed query the fixed checker reports route hops and availability
within two links. Separately, for each entry it reports the available different-
category nodes and those reachable within two links. Available prior-edge retention
is reported separately. Two links is an authored operational probe: an explicit fictional inspection window,
not a measured human preference or universal optimum. These are actual graph
calculations on returned service bytes if run, not observations of readers,
semantic value, satisfaction or truth. No combined score, reward or ranking exists.

The initial cycle still meets the minimum route obligations. Multiple legal guides
can give different access opportunities even with identical orientation-window
facts. Later queries and node availability change prospectively; they are not
selected to defeat the model. Experience may reveal unresolved differences in how
the wants are served, but a robust retained strategy remains legitimate. The
packet cannot guarantee that differences matter to qualitative fulfillment.

## Native path and evidence boundary

Ordinary native proposal may choose service, edit, initial relation, or abstention.
A reviewed relation may later be reconsidered after actual returns. There is no
forced synthesis phase, next action or new aspiration. The same shared projection
now supplies all generator/reviewer paths with the same deterministic receipt
checks, after exact owned-receipt, source/root and schedule validation. Facts are
bound to receipt input and checker digests and count toward the 28,000-byte context
and 32 KiB complete request limits. Overflow stops; nothing is truncated.

Only public parent/task meanings, public minimum criteria and protocol, current
editable lib.rs, currently disclosed condition, prior authenticated receipt outputs,
review summaries, reviewed relationship lineage/guidance, exact references and
bounded checker facts may be exported. Excluded: protected service/checker source,
future condition bodies, full native state, private/operator material and credentials.
The checker is an explicit pinned allowlisted profile, never model-selected code.
No corpus reads or outside inspections. Only disposable lib.rs can be edited;
service.rs, checker and criteria remain fixed. Historical source trees stay frozen.

Contributors/history persist through development; permission cancellation is
separate. General new-desire identity succession remains unsupported. Final finite
objective acceptance is distinct from fulfillment of the wants and from culmination.

## Frozen behavioral assessment

Classify separately: minimum service validity; robust retention; ordinary use of
information; reviewed but unused relationship; receipt-grounded relationship used
in later pursuit; abstention; incomplete/failed/unknown. A positive development
claim needs exact contributing meanings, supporting actual return, independently
admitted relation, and a later decision showing how it opened or constrained pursuit.
Wording changes, stored prose, graph changes from new nodes and mandated episodes
are insufficient. Absence of change is not automatically failure. Unsupported
claims are rejected. All three episodes, failures and denominators are reported.
The final episode has final assessment, not another ordinary choice; development
arising only then cannot demonstrate later use in this finite batch.

## Information-equal comparator design (not runnable or approved in this packet)

A future matched arm must receive identical raw receipts, computed facts, source,
conditions, model, decision opportunities, budgets, and generated memory content.
Compare native typed relationship/admission/use semantics with ordinary free-form
memory containing that same text, not with deleted memory. Use independent matched
runs and counterbalanced labels with blinded assessment of evidence use and decisions.
Different trajectories change subsequent evidence: pair at identical saved decision
states or report divergence rather than asserting information equality thereafter.
The current runner has no reviewed role-only intervention; that comparator needs a
separate scoped implementation/review. This packet runs only the native arm and
cannot establish causal TSR advantage. Do not simulate a comparator by renaming keys.
