## Goal

One item, with an operator decision. r3 made the hook evaluate shell expansions (globs, `~`, `$VAR`) so that its digest equals the argv `tsr exec` receives; the review found that emulation wrong in seven ways and slow in one (quoted globs expanded, `{}` splitting words, `$(…)` and `<(…)` mangled, empty expansions kept as words, dotfiles globbed, directory wildcards not expanded, an exponential glob matcher) and three parser defects (backslash-newline, `#` comments and here-doc bodies, a panic on a trailing `env -u`/`env -C`/`nice -n`). **Decision: the hook no longer evaluates expansions; it matches.** (a) The hook parses the Bash command with shell grammar only: quotes and escapes, backslash-newline continuation, `#` comments, here-documents (the body is data, not commands), `;` `&&` `||` `|` `&` newlines, subshells `( )` and groups `{ …; }` as whole tokens only (never splitting a word such as `{}` or `HEAD@{1}`), redirections in every form including `>&-`, `>&file`, `&>`, `>|` and process substitution `<(…)`/`>(…)` as one unit; prefixes `VAR=value`, `env [options]`, `time`, `nice [-n N]`, `timeout [options] DURATION`, `nohup`, `!` and `if`/`then`/`do`/`while` keywords are skipped before the command word; malformed input never panics (a trailing `env -u` or `nice -n` is a plain word list). (b) For the `tsr exec` simple command it records a pattern: its argument words after `--`, quote-removed, redirections dropped, and each word that the shell would expand — an unquoted glob, `~`, an unquoted or quoted `$…`/`${…}`, command or arithmetic substitution — recorded as a wildcard that matches any sequence of zero or more argv words (a quoted word with an expansion matches exactly one argv word); words with no expansion are literal. (c) `tsr exec` receives argv and reuses the hook's candidate when exactly one pending (proposed, not yet dispatched) candidate in its session's task has a pattern that matches its argv; it records argv as the dispatched args. `tsr forecast --args` pairs with the hook's proposal by the same matcher. Zero or several matching candidates: exec mints its own candidate as today and prints one stderr line saying why. (d) The matcher is linear in the argv length times the pattern length (no backtracking blow-up). Test, through `tsr hook` and `tsr exec` with m0_ordinary_session.rs's harness and a real `bash -c` for the command as the r3 review did: the r3 brief's spellings still give one proposal, one forecast and a log reconstruct accepts; and so does each defect spelling in the r3 review — `find . -name "*.toml"` with a Cargo.toml present, `find . -exec echo {} \;`, `git show HEAD@{1}`, `xargs -I{} echo {}`, `echo $(date)`, `diff <(echo a) <(echo b)`, `cargo test \` newline `--release`, `cargo test # run tests`, a here-doc with an apostrophe before `tsr exec`, `echo $UNSET x`, `ls *` with a dotfile present, `ls crates/*/Cargo.toml`, `time`/`nice`/`timeout -s KILL 60`/`nohup` before `tsr exec`; a trailing `env -u` exits 0; ten `*a` against a 40-character name returns in under a second; `timeout -s KILL 60 cargo test` and `timeout -k 5 60 cargo test` record `run_approved_test`.
