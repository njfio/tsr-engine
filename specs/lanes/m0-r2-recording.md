## Goal

One item: recording must hold up in an ordinary Claude Code session, not only in the restricted one the real-session fixture used. Today: (a) only a Bash command that starts with the literal `cargo test` counts as a test run (hook.rs:28-30, `ALLOWLISTED_TEST_PREFIX`), so `RUST_BACKTRACE=1 cargo test`, `env X=1 cargo test` or `cd crate && cargo test` is recorded as `Generate` with no dispatch; (b) `tsr exec -- sh -c 'a; b'` loses its forecast because the hook (which sees Claude Code's command string) and `tsr exec` (which sees argv after the shell split it) digest the arguments differently (hook.rs:139-160), so exec mints a new candidate with no forecast; (c) any other tool call — a Bash `ls`, TodoWrite, Read — is recorded `Generate` then `Committed` with no `Proposed`, which reconstruct rejects (lib.rs:94-96), so an ordinary session never yields a passing record.
