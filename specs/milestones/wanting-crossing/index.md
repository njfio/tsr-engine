# Milestone: Wanting crossing

Each cycle starts with one reading. Its want crosses without review, it goes out with an expected return, and returns come back beside it. Action stays gated.

The author made this decision on 2026-11-03. It applies *The Sovereign Mirror*: the crossing into wanting is free and the crossing into action meets resistance (ch. 10), Tune comes before Focus (ch. 7, 12), and returns come from someone real (ch. 13, 21).

This milestone doesn't try to show that a model wants anything nobody assigned (ch. 18). That needs its own detector and is not started.
