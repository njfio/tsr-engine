# Authenticated control observations in criterion assessment

This closes the aggregate-only input gap identified by the offline crossing/growth preparation. It does not launch either experimental arm or complete a live TSR cycle.

`criterion-evidence@v5` adds `authenticated_control_observations` to the counted independent assessment payload. The normal browser adapter first validates native receipt ownership, source lineage and admitted exports. The new projection selects exactly the frame's receipt and snapshot, retains native case order and raw observation bytes, and associates them with the existing `test_receipt` evidence ID. It adds no inferred criterion outcome. No attributed report can be substituted for a native case.

Missing detail is explicitly unavailable. Duplicate receipts/cases, stale snapshots and malformed case shapes fail closed. Captured details are revalidated through the authenticated projection before review and again before native apply. Changed bytes/order or disappearing observations cannot silently replace a resumed capture. Existing native criteria, prerequisites, findings, independent reviewer association and authority remain unchanged. The native frame retains its original aggregate receipt; the complete enriched input and transport proof are durably captured in the adapter and bound to the independent review invocation.

Versions 1–4 retain their original payload/instructions. Version 5 uses the existing durable single fresh reassessment only for settled internal contradictions, with no extra allowance or underlying execution retry. Legacy captures are not retroactively enriched.

The assessor is told that native protocol passed/met flags are configured-check outcomes, not fulfillment. Raw DOM observations establish what the protected probe reported at that source version; they do not prove hidden state, general reachability, human enjoyment, acceptance or a new desire. Partial coverage remains unknown. Independent games are not defects unless actual published criteria require interaction.
