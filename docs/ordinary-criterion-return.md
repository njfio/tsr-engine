# Ordinary returned evidence to Contrast

Prospective offline implementation; authored verification is not live TSR behavior.

The previous bridge required a current acceptance rejection to supply structured
Contrast. Ordinary browser observations and qualitative reflection supplied useful
facts and fallible prose, but did not produce named unmet criteria. Fixtures that
seeded acceptance rejection proved only the downstream preference mechanics.

The new optional `public-criterion-return@v1` profile connects an ordinary native
action return to a separate independent criterion assessment. It requires a
prospectively frozen publication of exact original criterion text, covered public
editable files/finite receipt facts, and evidence prerequisites. It never exports
protected checker source, command arguments, expected output or raw execution
logs. Guidance paraphrases are not substituted for original criteria. Unpublished
criteria remain unassessed. Explicit setup is not model-generated permission.

The reviewer uses the ordinary counted, source-bound transport and short evidence
references. It supplies semantic findings only. The host associates the response
with its exact request, retains the full authenticated response and binds native
application to the current source, receipt, publication and original requirements.
The source-origin label is not a claim to identify an originating model invocation.
The independent review's own invocation is authenticated and retained.

A complete map of Met/NotMet/Unknown findings is recorded as Council evidence.
Only supported NotMet findings create canonical Contrast. An explicit criterion-review
abstention is preserved without creating Contrast, even if its draft findings name
concerns; this is distinct from an independent narrative review rejection. Unknown is not unmet;
passing finite tests is not general satisfaction. A mixed prerequisite can expose
a static counterexample despite passing finite checks. This channel changes no
acceptance, fulfillment, contributor status, original obligation or action grant.
It uses existing native Preference expansion and Council eligibility downstream;
a new preference is an available reviewed choice, never required.

One assessment is permitted for an exact policy/publication/receipt/source frame.
An exact committed application can be recovered; a different second opinion for
the same frame is refused. New source, receipt or publication makes old findings
historical. An enabled current policy suppresses legacy acceptance-derived
Contrast until its own current assessment exists; it does not resurrect earlier
unmet findings when the latest evidence is unknown. Old records are not rewritten.

The ordinary browser post-action path invokes this independent assessment even
when no qualitative expectation was frozen. Where an expectation exists, its
interpretation and independent narrative review remain distinct. Criterion review
is a standalone additional counted call, not conditional on endorsing narrative
reflection. Both meanings remain fallible. The optional profile is pinned in a new
admission; existing frozen admissions do not silently acquire this stage. Its call
must fit the overall shared allowance/reservations (or existing unlimited policy).
There is no new uncounted transport or automatic retry after unknown effects.

Stop, pending effects, stale source and incomplete evidence fail closed. Native
finding and Contrast appends are atomic. Adapter restart verifies the retained
response instead of calling again. Fresh sessions must explicitly import exact
public criterion-return hashes alongside existing native lineage/export pins.

Limits: this is the checked-in PRD's Contrast-supported path, not direct book
validation or general evidence of spontaneous new wants. Successful composition
without Contrast remains a separate optional conceptual extension. Actual live
formation and behavioral influence require an authorized prospective evaluation;
all existing denied packets and campaign accounting remain unchanged.
