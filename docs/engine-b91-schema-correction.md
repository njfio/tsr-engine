# Bounded protocol correction for the real repair driver

This optional path addresses known-terminal generator schema failures. It does not repair generated code or decide that an experiment is meaningful. Normal native validation and separate review still decide whether a fresh proposal can proceed.

A fresh admission permits at most two additional generator requests across the six-stage trial: eight generator requests, six separately admitted reviewer requests and four real execution groups maximum. All attempts count against the existing shared campaign, including rejected responses. Earlier admissions retain their original six-call behavior. Original historical trials are not reopened.

A correction links the previous settled invalid request and exact validation code to the same current source-bound stage. The model must produce a complete new response. No identifiers are fixed, semantic fields removed, test expectations supplied or protected criteria relaxed. The existing bounded quarantine and response hash preserve the failure; repository policy forbids logging raw provider bodies. Unretained historical prose cannot be recovered or claimed as evidence.

Unknown dispatch, uncertain application, stale state, unknown usage, resource overrun and semantic rejection are not schema-correction opportunities. In particular, `return_basis_rejected` and `native_validation_rejected` are excluded because those broad errors can indicate evidence or semantic defects, not just repairable JSON shape. Interruption cannot refund a slot or repeat an uncertain request. Repeated invalid output stops at the finite allowance. This is protocol recovery, not a guarantee of semantic correctness or autonomous repair.

No provider-enforced strict-schema capability for the current Luna route is established by the installed transport. The separate legacy tool-call adapter is not evidence that Luna supports that mode. This change does not add guessed request parameters, change providers or weaken local validators.

Verification and the actual live outcome are recorded separately after completion. Deterministic fixture responses are not model-generated repair evidence.
