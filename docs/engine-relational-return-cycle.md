## Corrected integration defect

Previously, a new return invalidated old guidance pending reconsideration, but an
empty mechanical contrast blocked that reconsideration. The driver also stopped at
mechanical `satisfied` before checking pending review.

The controller now distinguishes contrast-backed expansion from review of existing
hypotheses. A newer return at the same observation revision can make an active,
nonwithdrawn existing hypothesis reviewable even if its parent predicates saturate.
Without contrast, only an eligible prior revision or an empty considered marker is
accepted; unrelated new aspirations remain forbidden. Evidence-key deduplication,
state binding and append-only history remain in force. A successful mechanical
state can consume a remaining model slot for review, then stops. It does not reopen
action selection, increase budgets or claim semantic success.
