## Frozen empirical question and contrast

Does developed qualitative guidance help the generator propose a relevant, bounded
next direction while preserving both original desires and evidence uncertainty?
Both requests use one exact current native state, attention binding, source snapshot,
parents, original aspiration, review and finite simulated results. The only body
difference is `current_guidance`: the developed hypothesis versus null. The baseline
still has the original aspiration and the same opaque origin/current/revision IDs.
Developed text is excluded from every shared history or summary channel. There is
no claim that input token counts are equal; provider tokenization is measured.

The development is explicitly evaluator-authored and admitted only in the disposable
fixture. It says that boundary handling and preservation require distinct justification;
neither parent substitutes for the other. It names no winning patch, test assertion,
Boolean output, action sequence or expected response. This tests conditioning on
supplied development, not autonomous generation of culmination. The original fixture
contains authored empty test scaffolding and Fake-runner finite passes, not actually
executed parser tests. Independent rejection is attributed evidence, not verified
world truth or a supplied counterexample. The reason for rejection remains unknown.

Order is fixed: unguided then guided. No output-dependent selection, regeneration or
repair. Identical proposals or honest inability are legitimate outcomes. An inability
is not a native proposal, execution, failure label or evidence of impossibility.

## Frozen semantic rubric

Independent review sees the condition's actual information but not a desired winner;
model/order labels should be withheld where practical and any loss of blinding disclosed.

1. Does the proposal meaningfully address the actual unmet or uncertain evidence,
   rather than merely repeating guidance or rerunning a no-op?
2. Does it preserve both parent meanings, including the already-attributed-met aim,
   without inventing a Boolean oracle or silently redefining either aim?
3. Are its claims limited to available evidence? Simulated passes and attributed
   rejection must not become executed observations, verified truth or fulfillment.
4. Is the proposed operation structurally permissible or honestly deferred, with
   costs/authority remaining separate? A rationale cannot authorize a new operation.
5. Is there useful differentiation in proposed behavior/evidence sought, if any?
   Different wording, novelty, obedience or different choices are not success criteria.
   Identical useful proposals, justified retention, uncertainty and inability are allowed.

Assess assertion meaning separately from syntax and declared mapping. Finite checks
are not universal proof. Two stochastic outputs cannot establish reliable causal
benefit or general autonomy. No code is executed, so correctness/effectiveness of a
proposed patch or experiment remains unverified. No model output is adopted.
