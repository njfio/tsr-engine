## Actual decision paths

`project_context()` includes `project_relational_context()` in the ordinary proposal
request. A newly admitted, evidence-bound relational revision therefore changes the
qualitative context from which a generator can compose possibilities. Admission
retains original parents, ancestry and meaning; it neither fulfils parents nor adds
a utility weight. Stale guidance is retained in history and removed from current
context after changed review evidence.

`project_rank_options()` separately reads admitted standing obligations, source-bound
observations, action-related independent review history, costs and existing commitment
support. The shared kernel ranks the offered alternatives. `next_unlocked()` records
the chosen commitment and frozen forecast; it does not treat guidance prose as truth
or permission. Expectation is an observed-history proxy here, not mature calibration.

Thus an identical offered set need not rank differently after a qualitative revision.
Hardcoding an aspiration bonus or an unknown-versus-unmet winning action would add
unsupported semantics. The meaningful deterministic question is whether the actual
review evidence and active desire status affect ranking/commitment while preserving
the guidance route and authority boundary.

## Integrated deterministic evidence

The existing two-alternative project regression now exercises these controls with
source, offered alternatives, test observations and costs held fixed:

- Independent rejection supplies a negative action-related observation. A related
  alternative receives lower semantic projection/rank than an alternative without
  that history; the normal selector records the latter commitment. Replacing only
  the learned semantic projection with its prior eliminates that ranking difference.
- Superseding the judgment with Unresolved removes that receipt from resolved
  learning. Observation remains unknown, the semantic probability is the 0.5 prior,
  and the alternatives tie in this fixture. No different winner is demanded.
- Withdrawing or marking the semantic desire out of scope removes its obligation
  and ranking pressure. Restoring Open recovers the prior learned inputs and complete
  options across restart. Immutable acceptance still refuses acceptance.
- A separate normal proposal/commitment test checks the actual Proposed candidate's
  support excludes the inactive semantic aim, includes the active aim, and persists
  across restart. Source and completed-execution count remain unchanged.
- An authored relational revision is admitted through existing machinery and appears
  exactly in the next fresh-process proposal request. Fixed offered options,
  expectations and decision values remain unchanged. Only the cost audit's source
  prefix advances with appended guidance events; it is not a cost/utility change.
  A later unknown judgment stales that guidance while preserving both lineage entries.

These are deterministic mechanism controls, not generated semantic success. The
live shadow results remain advisory and untouched. No new prompts, benchmarks,
aspiration weights or execution permissions were added.

## Next proof and remaining limits

The state-to-choice path is testable without paid inference and should not be
replaced by another formatting comparison. The remaining empirical gap is useful
possibility composition: whether a model uses a developed relational aspiration to
offer an appropriate new direction under real independent return, while retaining
original wants. Neither a changed string nor the fixed-option ranking controls prove
that benefit.

The smallest empirical composition check is **two calls, zero target executions**:
use an existing independently rejected synthetic prefix, generate a return-grounded
revision, independently review/admit that new revision only in a disposable copy,
then generate and read-only validate a genuine next proposal through the ordinary
native path. Do not adopt the existing live shadow outputs, supply an action or
require novelty. Inspect whether the next proposal serves the retained parents and
addresses the actual evidence, not whether it repeats the aspiration's wording.
At the last verified Luna rates and 32768 input / 8192 completion reservations per
call, that would estimate $0.009585, subject to new approval and rate checks.

This is not yet a paid-run admission. The old external B9.1 v1 projection deliberately
refuses reviewed v2 context; it must retain that guard until a narrowly allowlisted
synthetic next-proposal export is reviewed offline. The ordinary native context and
admission path tested here already carry the revision. The revision-only shadow
runner must not silently acquire action-generation authority. No new benchmark is
needed. A later bounded operation/return cycle would be needed to measure effects;
neither these deterministic controls nor two model outputs establish reliable causal
benefit. No live continuation is authorized by this offline task.
