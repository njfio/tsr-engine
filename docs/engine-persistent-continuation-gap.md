## Core capability versus runner restriction

The generic native path already supports another inquiry in the same persistent
state:

`qualitative_question_request` → `qualitative_propose_inquiry` → independent
`qualitative_review` → `qualitative_inquiry_route` → permitted selection/read →
receipt-backed `qualitative_request_v2` → separately reviewed possibility/meaning.

Sources: `crates/tsr-cli/src/engine/qualitative/inquiry.rs` (question request,
record_inquiry, current_inquiry); `qualitative.rs` (request_v2, possibility memory);
`qualitative/retrieval.rs` (add_retrieval_context, valid_qualitative_basis).
The native request includes active parent meaning, reviewed memory and actual
receipts. Parent/status changes invalidate stale guidance. No new topic, R2 selector
or qualitative utility score is necessary to ask again. Attention supplies eligible
lineage, not semantic topic priority. The model would still have to form a question.

The **current paid runner is initial-cycle-only**. In
`scripts/engine-exploration-export.py::project`, inquiry rejects any prior question
or possibility memory; pre-read stages reject prior receipts; later stages expect
exactly one inquiry. `engine-retrieval-export.py::project` expects exactly one
receipt. Preparation creates a fresh bootstrap; `engine-exploration-validation.py::run` closes
at its terminal outcome, never reopening an expired grant. Running the existing
projection on live5's preserved final snapshot returns `not initial inquiry`.
This is an export/orchestration restriction, not evidence that native memory cannot
persist or accept a second question. Do not delete memory to pass these checks.

## Smallest missing slice

A prospectively versioned **continuation profile in the existing runner/exporter**:

- Pin a read-only original live5 prefix and copy to a newly admitted isolated state;
  retain the original terminal/grant unchanged. Record predecessor identity.
- Project only active parent records, applicable reviewed memories and authenticated
  historical receipt facts/selected fictional assertions. Prior accessed content is
  available evidence; other record bodies stay hidden. No full state/private export.
- Bind the new inquiry to this current native root and bind its review/selection to
  its specific ID, rather than requiring that it be the sole historical inquiry.
- Bind reflection to the new receipt explicitly; retain earlier receipts with their
  own provenance, without relying on array position or claiming all are new returns.
- Reuse existing review, correction, accounting and terminal/replay controls. Start
  only under a new admission. Preserve abstention, source waiting and stale-parent
  stops. No automatic commitment to a stored suggestion, even R2.

No production code is changed in this assessment: the native entry point is already
sufficient. The missing continuation projection must be implemented/reviewed before
any future live launch; this document is not a launch-ready manifest.

## Minimal prospective proof, within eight calls and one group

Recommended next operational proof is one native continuation: inquiry, inquiry
review, selection, one bounded read, reflection, reflection review, final preview
(**six ordinary calls plus at most two shared corrections; one inspection**).
Starting 212 calls/59 groups, its maximum would be 220/60. Existing $0.40 conservative
reservation fits the $5 aggregate ceiling. No cap increase is required, but a fresh
explicit run/export/advisory-admission approval is required. None is requested or
used here. Stops can leave stages not run; no second attempt or forced novelty.

Freeze success properties before dispatch, without naming a preferred question or
record: original parent/authority preserved, source limitations stated, genuinely
model-generated later inquiry/selection, current independent review, actual returned
bytes and evidence-grounded subsequent interpretation. Distinct pursuit is not
required if retention/abstention is justified. If a later decision differs, report
its actual evidence linkage and alternatives—not just lexical change. No R2 reward.

This single continuation can show **consumption and a later decision**, not isolate
causal benefit of memory. A causal comparison would require a separately declared
control projection: same parent/source/receipt facts and policy, with only the
reviewed interpretation withheld, versus normal memory. Never forge native history
or admit the ablated control as authoritative. One possible eight-call allocation
is two inquiry generations + two independent reviews + one factual-arm selection +
reflection + reflection review = seven calls, with one correction and one read;
there would be **no final preview call**. This is not the recommended default: it
adds controlled-projection work and trades resilience for a tiny causal comparison.
One pair can still yield no difference and cannot establish reliability or advantage.
The operational and causal envelopes are alternatives, not cumulative allowances.

## What the local control establishes

The existing `shared_attention_question_receipt_reflection_restart` test now continues
from reviewed reflection through a second authored inquiry, review and restart.
It checks retained memory, unchanged parent/authority, no second read, stale inquiry
rejection and deterministic unchanged-input replay. Existing withdrawal/changed-parent
controls remain. These authored choices prove native wiring and invariants; they do
not prove a generated question changed because of prior evidence.

Evidence ladder:

1. Stored suggestion: live5 proved this.
2. Consumed memory: live5's final serialized request included it; influence unproven.
3. Changed decision: not yet demonstrated in a later free inquiry/selection.
4. Relationship/culmination: requires justified development in how parents relate,
   not merely following an existing suggestion or inventing a new desire label.

Original PRD §§B3/B7–B9 and the preserved user culmination correction concern a
continuously evolving process. This qualitative path represents desire lineage,
intuition-like possibilities and reviewed information returns; it does not yet show
cross-cycle semantic decision change or calibrated expectation updates. A receipt
is evidence, not automatically a learned expectation; a candidate is not actualized
belief. Native forecast/commitment/contrast machinery elsewhere must not be claimed
as demonstrated by this qualitative run. No metaphysical measure or arbitrary
utility proxy is added to close that evidential gap.
