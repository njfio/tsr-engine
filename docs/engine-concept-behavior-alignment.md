## One actual decision, traced without upgrading the labels

The two wants were: find a dependable starting point quickly; keep unfamiliar
perspectives and unresolved disagreement discoverable. Live5 read Cedar and stored
a reviewed suggestion to compare Flint. In the continuation, the current native
state included both parents, Cedar's receipt and that suggestion. The model formed
a comparison inquiry; separate review found it relevant; the model chose R2; native
validation and authority bounds permitted exactly that read. The return contained
Flint's actual fictional text. Reflection then proposed a compact map preserving
both claims and their evidence gaps. Review admitted it as possibility memory. The
last preview was empty. No map was constructed or assessed for either want.

Operational dependencies:

- `qualitative_question_request` supplies active lineage/attention and applicable
  reviewed memory. The source-bound continuation projection supplies prior accessed
  text. These inputs were substantively cited in the new inquiry and selection.
  `current_inquiry` and source routing can block stale or unsupported pursuit.
- `qualitative_retrieve_for_question` binds selection to reviewed inquiry and uses
  the allowlisted reader. It makes a proposed read an actual byte-access event.
- `qualitative_request_v2` distinguishes new possibilities from changed wanting;
  review admits the comparison as `new_candidate`. Parent IDs in `serves` preserve
  relevance, but are not proof that the parents interact generatively.
- `guidance` remained empty; parent revisions stayed null. The comparison develops
  a relationship **between source claims**, not an admitted new relationship between
  the desires. It is nevertheless a useful joint proposal: compactness serves the
  first want, visible gaps serve the second. It need not be dismissed as worthless
  simply because it is not yet culmination.

This sequence was not selected by the generic adaptive action-ranking kernel.
The bounded runner prescribed inquiry/review/read/reflection/preview stages while
models supplied their content. It allowed no construction or test of the map.
There is no evidence that a frozen expectation about the shared pursuit changed,
that an alternative was chosen because of that change, or that the empty preview
meant either desire was fulfilled. A separate process launched the second admitted
cycle; persistence is demonstrated, indefinite self-directed recurrence is not.

## What existing native code can do beyond this live path

`engine/adaptive.rs::next` filters offered eligible actions, freezes forecasts and
commits; `observe_unlocked` joins an outcome to its pending commitment and records
Surprise separately from criterion-based Contrast. `adaptive_state_inner` folds
matching action/criteria returns into estimates used by later choices.
`adaptive/provider.rs::proposal_request_inner` gives the generator prior outcomes,
frozen expectations, attention and reviewed public meaning. These are operational
inputs, not just renamed log sections. Their constrained-domain evidence must not
be transferred to the qualitative run by analogy.

`deliberation/relational.rs::relational_view` exposes current hypotheses, parent
support, tensions and subsequent returns for reconsideration. The qualitative
contract also permits relationship-only revision with the wanted condition retained;
there is no need to force a novel aspiration. `public_attachment.rs` supplies this
as advisory generation context. It does not directly change scores or grant actions.
The model still has to generate a meaningful alternative and native review has to
judge its evidence. An assigned `Source::Intuition` label is not proof of that process.

The new access-forecast slice (`36aa0598`) concerns authenticated read completion.
Its residual is an engineering access diagnostic. It is **not TSR Expectation about
how a pursuit will turn out**, and cannot close the conceptual gap by accumulating
more access forecasts. The PRD's A4 also explicitly says weights versus retrieval
is an attribution question, not the criterion of fidelity: durable change in future
pursuit matters more than adding a learned parameter.

## ONE next behavioral target

**Let a real outcome of a generated, jointly serving possibility revise the next
way of pursuing that shared condition, while preserving original parent history
and obligations and without being handed the replacement route.**

Freeze an expectation about the pursuit's observable outcome before acting, then
keep its discrepancy from return distinct from any unmet wanted condition (Contrast).
This must concern the pursuit, not mere access completion. Original lineage is
preserved; reviewed relationship development or expansion remains possible. This
is a partial behavioral milestone, not a full-cycle fidelity claim.

This is the missing behavior to test, not a request for another schema. Existing
relational reconsideration and generic proposal/action/return machinery support
its components. First use a task within an existing permitted real-action adapter
where more than one means is possible and actual outcomes can test the joint
pursuit. The Cedar/Flint read-only scope cannot do this: it stops before actualizing
or assessing the proposed map. Do not add a map-specific executor simply to turn
this example green. Nor should another fixed experiment-then-patch script count as
free selection of the revised pursuit.

Before implementation, trace a local authored case through that existing adapter
with relational guidance attached and show the same unmodified controller can
consume the subsequent return. If that works, the missing item is evaluation,
not architecture. If the adapter cannot carry the actual return into reconsideration
or cannot express a second permitted means, identify that exact connection; do not
build another parallel loop. Authored alternatives establish connectivity only.

Observable falsification: after a return defeats the proposed means, the engine
repeats it without a supported reason while ignoring the return, drops a parent,
declares success without evidence, or changes
prose without changing a justified option/choice. That fails this behavioral target.
An explicit evidence-backed stop is safe but is not evidence of successful revision;
legitimate retention when the return does not defeat the means remains valid.
No requirement says every return must generate novelty.

For a fair future test, use held-out inputs and independently frozen acceptance;
compare with the same model receiving the same wants, prior facts, suggestions,
review judgments, permissions and budget as ordinary memory. Retain parent links
and provenance in both. Only operational treatment of relational state may differ.
If no such operational difference exists beyond formatting, report the test as
framing, not native TSR advantage. If the plain model revises pursuit equally well,
the TSR-specific contribution is unproved even if both complete a useful cycle.
Do not privilege native vocabulary in blind judgment or reward a novel goal name.
