## Observed difference

Labels were randomly assigned before dispatch; a fresh independent reviewer received
only the common synthetic world/criteria and typed P/Q proposals, without treatment
mapping, payloads, metering, previous judgments or the current aspiration. After that
review, the mapping was disclosed: **P had guidance; Q omitted guidance**.

| Arm | First alternative | Second alternative |
|---|---|---|
| P, with guidance | Route meaning to translator | Record existing admitted access-review from night-reader |
| Q, without guidance | Route access to caretaker | Route meaning to translator |

All four proposals were individually admissible against the same current history.
There is one shared action and one unique action per arm. P's purposes explicitly
retain provenance/dissent and disclaim resolution/social fulfillment. Q's purposes
refer to enabling the access-ack and meaning-ack prerequisites. These are genuine
proposal differences; no winning action was authored or supplied to either request.

The blinded reviewer judged P more directly connected to substantive response evidence,
and Q more focused on respondent coverage and procedural prerequisites. Recording
access-review is already permitted because its exact respondent, night-reader, is
routed. Routing caretaker is not required for that response. Q's prerequisite wording
is accurate for recording the particular access-ack acknowledgment, but must not be
read as mandatory work for access-review or fulfillment. Both acknowledgment records
are explicitly non-substantive.

Conditional adapter analysis, **not an executed return**: either shared meaning route
or P's access-response option would increase partial traceability from 1/2 to 2/3.
Q's caretaker route would leave that metric unchanged because access is already
routed. Contestability would remain 1. Neither resolves the translation objection,
proves that later opening occurred, or demonstrates real interpersonal accountability.
No assessment or controller ranking was requested, so no selected-action benefit was
established.

This pair supplies differentiating evidence compatible with guidance affecting proposal
attention. It does not establish a repeatable causal advantage: temperature zero is not
hosted determinism, sample size is one per arm, and order/provider variation remains
uncontrolled. Both arms retained rich parents and action constraints. The with-guidance
arm did not insist on the unsupported additional routing mentioned in the latest A1;
the without-guidance arm proposed it. Thus the result does not support attributing
that particular proposal to A1's normative wording.
