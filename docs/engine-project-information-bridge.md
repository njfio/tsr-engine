# Project information bridge and prospective batch

This is local integration work, not a live behavioral result. The previous repair
and its separate native acceptance remain unchanged. The campaign ledger still
has 222 calls, 61 groups and $0.180395 settled.

The generic project cycle now has an opt-in, independently reviewed information
detour. A proposal names active public parents, an inquiry, uncertainty, relevance,
allowlisted record IDs and a forecast of access completion. Native preview and
review bind the proposal to the current source and public meaning. Only explicit
operator corpus/exploration admission permits the later read.

The existing descriptor-relative bounded reader produces an authenticated receipt
of exact accessed bytes. Durable intent precedes I/O. A failed or interrupted read
remains unresolved and cannot automatically repeat. Receipt and access-only
Surprise settlement are committed together in the existing engine transaction.
The information receipt does not mark task criteria met, create negative task
Contrast, update repair success counts or establish truth of record assertions.

The receipt enters the existing relational context and can make an existing
reviewed relationship eligible for reconsideration. Retention is valid. Subsequent
possibilities use the ordinary native project path; no topic, replacement meaning
or action sequence is prescribed. An information choice is not ranked against a
patch using its access probability: PRD B7 requires a common task-acceptance event
for unlike-action ranking. This is the bounded uncertainty route, not a learned
value-of-information model or proof of adaptive TSR behavior.

`project information-configure` and `project information-resume` are explicit
native boundaries. The prospective Python v4 profile projects only the pinned
fictional corpus and task-local advisory evidence. Earlier release profiles do
not gain read authority. Generation/review contracts distinguish
`information_access` from protected-test observations; source claims cannot be
relabeled passing tests. Prepared reads block acceptance and episode replacement
or closure until their disposition is known.
