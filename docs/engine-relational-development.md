## Implemented separation

Normal relational requests now use shared development instructions. The synthetic
projection presents original parent meanings, bounded original and current relational
meaning, the actual return, and adapter measurement limits separately. Original meaning
is a revisable generated hypothesis, not an invariant belief or new authority. Existing
local requests retain complete history and receive the same instruction contract.

A revision carries a typed `development` object:

- `original_revision` and `prior_revision`: exact lineage bindings;
- `retained_meaning`: parent contributions and meaning retained or questioned;
- `return_reveals`: what the cited event/evidence establishes;
- `unresolved`: uncertainty and contrary evidence;
- `proposed_development`: a proposed change, or null for no new insight.

A null proposed development keeps the prior relationship/aspiration/discriminator
verbatim while recording return commentary separately. This prevents silent replacement
under a no-change declaration. A non-null development may genuinely revise or question
prior interpretations; it need not preserve unsupported routing claims. Empty proposals
remain allowed. New relations use development:null; revised relations use the separated
object. Distinct schema branches express this difference before generation.

Rust stores the annotations in append-only revision history and validates bounds,
lineage and no-change consistency. Original IDs, parent text, acceptance conditions and
authority do not change. The new optional field is omitted when absent during historical
serialization, preserving old proposal identity. Old unseparated submissions remain
readable/compatible and explicitly labeled legacy/unverified. New normal model paths
require separation on revisions. Local request provenance is versioned v2.

**No semantic quality is certified.** A model can explicitly propose a metric-only
replacement and pass structural checks; tests deliberately preserve that distinction.
Its semantic status and discriminator result remain unknown. There is no keyword-based
novelty detector, forced narrative, new value theory or numerical culmination score.
Whether the separation improves meaning requires independent evaluation.
