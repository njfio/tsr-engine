# Read-only published contributor history

`tsr engine … project acceptance published-history` returns authenticated public guidance publications, their contributor identities, requirements revision, source/scope provenance and current administrative status. Eligibility is computed separately using the existing native guidance rules. It grants no authority and does not mutate the episode. Private acceptance criteria and review prose are excluded.

TSR Studio binds this read to the same native root and source snapshot as the current-state response. Stale or failed reads are labeled unavailable, not interpreted as absent desires. The inspector separates active contributors from retained published meanings and exposes publication/lineage details. Queued feedback remains saved once; it is not falsely marked native-admitted or model-consumed. Run remains blocked both by unresolved accounting and, independently, by any input that has not obtained native admission.
