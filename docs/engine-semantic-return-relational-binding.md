# Independent semantic return reopens relational reconsideration

This is an offline core correction following the actual linked Trial 11 acceptance.
It implements PRD B2's common-snapshot views and B8's return-informed development;
it does not turn independent review into execution permission or a truth oracle.

## Reproduced omission

`project_relational_inputs()` previously bound source, published parent meanings,
tool receipts and supplemental outcomes. An independently rejected candidate could
leave all those inputs identical. Consequently an admitted aspiration remained
current and its revision was rejected as having no changed evidence, despite a new
semantic Return and dimensional Contrast. The regression held source and tool
receipts fixed; its first run failed on identical old/new relational bindings
(`target/relational-semantic-return-before.log`).

## Narrow correction

After a native independent review exists, the context uses `project-relational@v2`
and binds its exact identity, current applicability, and unmet/unknown dimensions
limited to already-published parents. The existing ordinary native proposal request
includes this context. No private review prose, unpublished criteria, aggregate
private counts or inferred tool observations are exported. Operator provenance is
checked. Historical guidance is preserved but becomes stale; a fresh source-bound
revision can be proposed and independently admitted using the existing contract.
Rejection and unknown remain different. No numerical emergence score or new goal
is introduced, and no execution follows from a revision.

Before any review, the v1 wire shape and binding remain unchanged, preserving the
historical live trial prefixes. Existing parent withdrawal/restoration filtering
continues to apply. New source invalidates review applicability; a stale semantic
judgment is not advertised as current evidence.

## Boundaries

The fixed B9.1 synthetic external transport continues to allowlist its original
six-stage payload. It explicitly rejects reviewed v2 input before reserving or dispatching any call,
rather than silently omitting its semantic evidence. It does not export independent
acceptance review content. The native proposal path is repaired; a future external semantic-review
continuation needs an explicitly allowlisted synthetic projection and a fresh live
admission. No historical result or paid request was changed to claim this repair
improved model reasoning.

Regression fixtures are authored, use Fake workers and establish mechanism behavior,
not genuine generated culmination or reliable semantic judgment. The accepted parser
repair remains one synthetic observation, not mature calibration or causal advantage.
