## Fresh quickstart verification

One installed `qwen2.5-coder:32b` call produced the two-file repair directly. It chose checked
multiplication with an overflow fallback and subtraction guarded against underflow. No reference
answer was supplied. The controller assistant inspected these semantics separately, recorded all
three requirements as met after sealed tests passed, and exported the accepted snapshot.

The next episode starts from original broken source; it inherits requirements and reviewed
outcomes but is not accepted. That distinction was checked by an actual refused accepted-only
export. Earlier [genuine-model carryover](engine-local-correction.md) already demonstrates another
proposal/action in such a later episode, so this audit did not repeat that costly local validation.

- Existing real RTS full-suite evidence reused: **999 passed, 15 ignored**, unchanged source.
  No new RTS candidate or executor logic changed in this audit, so rerunning that suite was unnecessary.
- No paid/external inference, downloads, push or deployment. Temporary provider stopped. Existing
  unrelated untracked files preserved. External correction is superseded by local success and must
  not be dispatched.

## Honest remaining limits

Operator review is required. The operator defines a legitimate task contract, publishes suitable
feedback and determines semantic acceptance; this is not unattended autonomy. This audit's review
is by the controller assistant, separate from the local model, not an independent human oracle.

Generation quality varies by installed model. Context and edit units remain bounded, and source
window preflight needs care. Compiler errors may still be classified as `unavailable`; they do not
produce acceptance. History/expectation estimates are simple explicit proxies, not calibrated
confidence or proof of correctness. Carryover is explicit and requirements-compatible, not private
session mining. Larger-task reliability and easier contract preparation are improvements, not
missing implementations of the demonstrated functional cycle.

M3's corpus/statistical gate, held-out superiority, fine-tuning and long-horizon research claims
remain unproven. They are separate from delivery of this operator-assisted functioning system.
